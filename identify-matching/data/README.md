# External identity-matching data

Download `mating_clips.csv`, the mating-event videos, and the rooster logs from
the public dataset listed in the top-level README. Place them here as:

```text
data/
├── mating_clips.csv
├── rooster_logs/<clip_name>.csv
└── videos/<clip_name>
```

Every video and rooster-log filename must match a `clip_name` value in
`mating_clips.csv` exactly.
